# 사주페어링

**헤어진 그 사람과 다시 만날 수 있을까?**
두 사람의 사주로 재회 가능성과 최적의 타이밍을 분석해 드리는 웹 서비스입니다.

## 서비스 소개

사주페어링은 이별 이후 "그 사람은 지금 나를 어떻게 생각할까", "언제 연락하는 게 좋을까"가 궁금한 분들을 위한 재회 사주 분석 서비스입니다.
생년월일과 이별 상황을 입력하면 두 사람의 사주를 바탕으로 궁합과 재회 가능성을 분석해 줍니다.

## 주요 기능

### 무료 궁합 분석
- 두 사람의 생년월일(시간을 모르면 생략 가능)로 사주 원국표, 오행 구성 비교, 일지 합·일간 상극, 궁합 점수를 확인할 수 있어요.
- 별도 결제 없이 바로 결과를 볼 수 있습니다.

### 심층 분석
- 상대방 속마음, 새로운 인연 가능성, 재회 가능성(%), 재회 최적 타이밍, 효과적인 접근법, 재회 후 지속 가능성, 지금 당장의 행동 지침, 종합 총평까지 8가지 항목을 제공합니다.
- **첫 1회는 무료 이용권**으로 체험할 수 있고, 이후에는 간편결제(카카오페이·네이버페이) 또는 카드로 이용할 수 있어요.

### 결과 보관과 공유
- **사주보관**: 심층 분석 결과를 마이페이지에서 다시 볼 수 있습니다. (결제일로부터 7일간 보관)
- **PDF 저장**: 결과를 PDF로 저장해 영구 소장할 수 있어요.
- **링크 공유**: 결과를 링크로 다른 사람에게 보여줄 수 있습니다. (7일간 유효)

### 그 밖에
- 카카오 로그인, 결제 내역 조회, 회원 탈퇴
- 모바일에 맞춘 화면 구성

## 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| 프레임워크 | React 19, TypeScript, Vite |
| 스타일 | Tailwind CSS |
| 라우팅·폼 | React Router 7, React Hook Form, Zod |
| 사주 계산 | [`@fullstackfamily/manseryeok`](https://www.npmjs.com/package/@fullstackfamily/manseryeok) (만세력) |
| 백엔드 | Supabase (인증, 데이터베이스, Edge Functions) |
| 결제 | PortOne |
| 결과 저장 | html2canvas, jsPDF (PDF 저장) |
| 분석 | Google Analytics 4 |
| 배포 | Vercel |

## 프로젝트 구조

```
src/
├── components/   # 화면 컴포넌트 (홈, 입력, 결과, 결제, 마이페이지 등)
├── lib/          # Supabase, 결제, 분석 요청 등 외부 연동
├── utils/        # 사주 계산·결과 가공 로직
├── constants/    # 사주 관련 상수
├── types/        # 타입 정의
├── mocks/        # 목 데이터
└── assets/       # 이미지, 아이콘
```

## 배포

[Vercel](https://vercel.com)에 연결되어 있으며, `main` 브랜치가 운영 환경으로 배포됩니다.
`develop` 등 다른 브랜치는 별도의 프리뷰 환경으로 배포됩니다.
